# Encode Lessons in Structure

When a correction recurs or the same instruction needs repeating, encode the rule in a lint, metadata flag, runtime check, or script where it can be enforced. Verify that the mechanism catches the original mistake.

If the lesson needs judgment and cannot be encoded, make the instruction more prominent and add an example of the failure mode.

**Corollary:** If the fix is structural, only use the structural fix. The instruction is the symptom.
